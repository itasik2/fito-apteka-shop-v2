# Фито-аптека — Next.js eCommerce (Натуральная косметика и травы)

Полностью рабочий стартовый сайт продажи фитокосметики и трав на Next.js.

## Запуск локально

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```
Открой: [http://localhost:3000](http://localhost:3000)

- Каталог `/shop`
- Админка `/admin`
- Тестовые товары: масла, сборы, кремы.
- Stripe подключается по желанию.
